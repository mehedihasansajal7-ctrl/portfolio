About this project

A public welfare and zakat application portal for SFUWT Welfare Trust. Applicants move through a guided, multi-category wizard — Medical, Education, Marriage and Financial — instead of downloading a form and emailing a scan.

The server validates every field, enforces the workflow order, and produces a printable application in Bengali plus a full PDF pack for the review committee.

What it does

  • Four application categories, each with its own required documents and rules.
  • Mandatory applicant photo, compressed in the browser to fit the edge body limit; large files upload in chunks.
  • Uploads are validated by magic bytes and the MIME type is derived server-side, never trusted from the client.
  • Workflow transitions are enforced on the server; a client cannot set its own status.
  • Applicant tracking with application number + mobile, rate-limited against guessing.
  • Printable application form and a full PDF pack using a bundled Bengali font.
